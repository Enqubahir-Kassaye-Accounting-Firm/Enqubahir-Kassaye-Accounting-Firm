# client/

Everything the client's site is built from. `/aksumite-template` copies the
handover folder here and reads this folder.

| File                 | What                                                                 |
| -------------------- | -------------------------------------------------------------------- |
| `blueprint.md`       | Project Blueprint text (required)                                    |
| `brand.md`           | Brand Guideline text, if made. Colours, fonts and voice come from it |
| `logo.<png/svg/jpg>` | Best logo file, if any; `logo-light.<ext>` for dark areas, if any    |
| `photos/`            | Hero, project and team photos, partner logos. Landscape for the hero |

The PDFs and Word files stay in the client's company folder. The AI reads the
`.md` text, which costs far less than a PDF.
