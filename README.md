# enqubahir-kassaye-accounting-firm — website

Static business website: Next.js + React + TypeScript + Tailwind CSS. All
content lives in code; deployed to Vercel or as static files.

## Quick start

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000.
